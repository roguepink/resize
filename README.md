# 写真リサイズ

写真をえらぶだけで、ぐっと小さくするアプリ。何枚でもまとめてOK。
小さくした写真は、そのまま **LINE などで送る**か、**まとめて保存**できる。
写真はスマホ(ブラウザ)の中だけで処理し、どこにも送らない。位置情報(どこで撮ったか)も自動で消える。

**使う: https://roguepink.github.io/resize/**

## 使い方

1. 大きさをえらぶ(「一番小さく」= 長い辺 800、1枚 100KB くらい / ふつう 1200 / きれいめ 1600)
2. 「写真をえらぶ」→ 写真を何枚でも選ぶ
3. できあがったら「LINEなどで送る」(送り先を選ぶ画面が出る)か「まとめて保存」

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ使える
- **LINE の中で開いたときは「送る」ボタンが使えないことがあり、ホーム画面にも入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選ぶ
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても使える

## 中身

- `index.html` 1枚で完結(外部ライブラリなし)。`manifest.webmanifest` と `sw.js` でホーム画面・オフライン対応
- 縮小は半分ずつ段階的に行い、JPEG(品質 0.8)で書き出す。もともと小さい JPEG はそのまま
- アドレスの末尾に `#play` をつけると、作ったテスト画像3枚で動作確認できる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
